# 🎨 Etch-a-Sketch

Project developed as part of **The Odin Project – Foundations**, focused on **DOM manipulation**, **event listeners**, and **JavaScript logic**.

The goal of this project is to recreate an **Etch-a-Sketch** in the browser: an interactive grid where the user can draw by hovering the mouse over the squares.

---

## 🚀 Demo

You can view the live result of this project here:

🔗 **[https://jormaedes.github.io/Etch-a-Sketch/](https://jormaedes.github.io/Etch-a-Sketch/)**

When hovering over the grid, the squares change color, simulating a drawing effect.

During this project, I practiced and consolidated:

* Use of **event listeners** (`mouseover`, `click`)
